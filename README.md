# law-school
Flow chart outlines for 1L courses

## Open the charts in draw.io

The `.drawio` files are editable flowcharts. Open them in the free [draw.io online editor](https://app.diagrams.net/) to view, zoom in, and make your own notes.

### Download and open a chart

1. Click a `.drawio` file in this repository, such as [Torts.drawio](Torts.drawio) or [Civ Pro.drawio](Civ%20Pro.drawio).
2. Click **Download raw file** in the file toolbar on GitHub. Keep the `.drawio` file extension. If GitHub displays XML or code, download the file rather than copying that text.
3. Go to [draw.io](https://app.diagrams.net/). If asked where to save diagrams, choose **Device**.
4. Click **Open Existing Diagram** and select the downloaded file. If the editor is already open, use **File → Open From → Device** instead.
5. Use the zoom controls to explore the chart. If it has multiple pages, use the page tabs at the bottom to switch between them.

You can edit and save your downloaded copy without changing the original chart in this repository. To download all charts at once, use **Code → Download ZIP** on the repository's main page, extract the ZIP, and open the `.drawio` file you want.

### Open directly from GitHub

1. Open [draw.io with GitHub storage](https://app.diagrams.net/?mode=github).
2. Click **Open Existing Diagram**, then sign in to GitHub and authorize draw.io if prompted.
3. Browse to **Jdcruz831/law-school**, select the **main** branch, and choose a `.drawio` file.

Saving changes back to this repository requires write access. Use the download method above if you just want your own copy.

For more help, see the official draw.io guides for [opening diagram files](https://www.drawio.com/docs/manual/open-diagram-file/) and [working with GitHub](https://www.drawio.com/docs/integrations/github/).
